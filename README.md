Projet minimaliste visant à réutiliser mes compétences acquises lors de ma dernière expérience en entreprises:

Technos utilisés:
- NestJS: Frontend
- ReactJS: Backend
- PostgreSQL: BDD
- Prisma: ORM
- Docker: Conteneurisation
- Github: Code source
- GithubAction: CI/CD
- Terraform: IAC
- Azure: Plateforme Cloud

- Docker/docker compose
- Terraform
- CI/CD
- Gestion du dépot Git.

Contexte du projet:
Gestionnaire de tâches minimaliste permettant d'ajouter et de supprimer des tâches à faire.
